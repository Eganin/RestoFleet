# Сборка пояснительной записки курсовой

Два скрипта на Python (решение 217):

- `figures.py` рисует схемы для записки в `docs/coursework/img/<id>.png`: matplotlib, 200 dpi, ширина не больше 16 см, шрифт DejaVu Sans.
- `build_docx.py` собирает `docs/coursework/*.md` в `docs/coursework/RestoFleet-coursework.docx` по ГОСТ 7.32-2017 и проверяет записку. Отчёт о проверке печатается в stdout.

Порядок файлов и соглашения разметки описаны в `docs/coursework/README.md`.

## Окружение

Зависимости ставятся в venv вне репозитория. Проверено на Python 3.14, matplotlib 3.11.2 и python-docx 1.2.0; Pillow и lxml подтягиваются как зависимости.

```sh
python3 -m venv /tmp/rf-venv
/tmp/rf-venv/bin/pip install 'matplotlib==3.11.2' 'python-docx==1.2.0'
```

Скрипты запускаются с флагом `-I` (изолированный режим): так текущий каталог и `PYTHONPATH` не влияют на импорт. Пути скрипты вычисляют от своего расположения, поэтому запускать их можно из любого каталога.

## Сборка

```sh
/tmp/rf-venv/bin/python -I tools/coursework/figures.py        # все схемы; можно перечислить id: … figures.py er-model
/tmp/rf-venv/bin/python -I tools/coursework/build_docx.py     # docx и отчёт
/tmp/rf-venv/bin/python -I tools/coursework/build_docx.py --check    # только отчёт, без docx
/tmp/rf-venv/bin/python -I tools/coursework/build_docx.py --strict   # код возврата 1, если в отчёте есть ошибки
```

Дополнительные ключи `build_docx.py`:

- `--src DIR` — другой каталог исходников. Пригодится, чтобы проверить черновик в копии.
- `--out FILE` — другой путь к docx.

Файл `RestoFleet-coursework.docx` в `.gitignore`. Финальную версию собираем на закрытии этапа, тогда же решаем, коммитить ли её.

## Что делает `figures.py`

- Рисует все схемные маркеры `[[FIG: …]]`. Содержание берётся из описания в маркере и из текста вокруг него, факты сверены с кодом: `shared/protocol` (Topics), `V1__core.sql`, `deploy/docker-compose.yml`, `deploy/toxiproxy.json`, `ProbeStateMachine`, порты `agent:domain`.
- Снимки экрана (`agent-wizard`, `agent-status`, `swagger-ui`) не рисует: их снимают при валидации КМ5 и кладут в `docs/coursework/img/<id>.png`.
- Печатает предупреждения: маркер без схемы, схема без маркера, подпись за краем холста, подписи, наложившиеся друг на друга.
- Обрезает PNG по содержимому. Холст рисуется в масштабе 1:1 к странице, поэтому кегль на рисунке равен кеглю в печати: от 5,7 pt (метки PK/FK на ER-диаграмме) до 10 pt.

## Что делает `build_docx.py`

Оформление:

- **Страница:** A4, поля 30/15/20/20 мм.
- **Основной текст:** Times New Roman 14, интервал 1,5, абзацный отступ 1,25 см, выравнивание по ширине, переносы. Интервалы до и после абзаца — 0.
- **Заголовки:**
  - структурные элементы — по центру, прописными, полужирным;
  - главы — с абзацного отступа, каждая с новой страницы;
  - в заголовках переносы запрещены.
- **Рисунки:** по центру, ширина не больше 16,5 см, высота не больше 22 см (у портретных снимков экрана — не больше 13 см). Подпись под рисунком: «Рисунок N.M — …». Если PNG нет, вместо рисунка ставится рамка с описанием и жёлтой пометкой «[рисунок будет добавлен]».
- **Таблицы:**
  - подпись над таблицей слева;
  - шрифт 12, интервал одинарный, границы сплошные;
  - шапка полужирная и повторяется на новой странице;
  - ширина столбцов рассчитывается по содержимому.
- **Листинги:** Courier New 10, интервал одинарный.
- **Inline-разметка:** `**жирный**`, `*курсив*`, `` `код` `` (моноширинный, без фона).
- **Списки:** маркер — тире «–». Нумерация берётся из исходника.
- **Список источников:** номера берутся из файла.
- **Приложения** (`appendix-*.md`, заголовок `# Приложение А — Название`): «ПРИЛОЖЕНИЕ А» и название по центру, каждое приложение с новой страницы. Рисунки и таблицы нумеруются «А.1».
- **Колонтитулы:** номер страницы внизу по центру, на титуле его нет.
- **Содержание:** поле TOC (уровни 1–3) и `w:updateFields`, поэтому Word при открытии предложит обновить поля.
- **Титульный лист:** только поля-заглушки в квадратных скобках.
- **`[[TODO…]]`** выделяются жёлтым.

Проверки (выводятся в отчёте):

- **Структура:** нумерация заголовков `N`, `N.M`, `N.M.K`.
- **Рисунки:**
  - все маркеры разобраны;
  - номера идут по главам;
  - вне глав рисунков нет;
  - id не повторяются.
- **Таблицы:**
  - номер в подписи совпадает с порядковым;
  - у каждой таблицы есть подпись;
  - число ячеек в строках совпадает с шапкой.
- **Ссылки «рисунок / таблица N.M»:**
  - указывают на существующие номера;
  - на каждый объект есть ссылка;
  - первая ссылка стоит до объекта.
- **Источники:**
  - номера `[n]` (в том числе `[2; 3]` и диапазоны) не выходят за список;
  - источники упоминаются в порядке первого упоминания;
  - в списке нет неупомянутых источников;
  - нумерация списка идёт подряд.
- **`[[TODO…]]`:** список с файлом и строкой.
- **Оформление:** строки листингов длиннее ширины полосы (Word их перенесёт) и листинги длиннее 12 строк.
- **Объём** по файлам: знаки без разметки и оценка числа страниц (1800 знаков на страницу).

Что остаётся на Word при финальной вёрстке:

- обновить поле содержания (номера страниц);
- поставить «Продолжение таблицы N.M» над перенесённой частью таблицы: страницы известны только после вёрстки;
- расстановку переносов Word выполняет сам.
