## Отложенные minor M3

M1 `connectedOnce`-гонка; M2 утечка линка при отмене во время connect; M3 дубли после таймаута публикации; M4 Lab теряет причину; M5 порядок start/stop `AgentService`; M8 `ts` will = время connect; M9 битая команда молча отбрасывается; M10 `watchedApps` не применяется к package events/телеметрии; M12 неполный провижининг DynSec не чинится повтором; M13 Koin-lookup в лямбдах; M14 дубль regex пакета без лимита длины; M15 интервал телеметрии применяется после текущего сна; M16 цели проб из тени не ограничены; 3.8: `dynsec-dev.sh` на bash 3.2 печатает `new_clients[@]: unbound variable` (rc 0).
