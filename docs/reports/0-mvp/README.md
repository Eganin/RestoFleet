## Тезисы для главы «Обоснование осуществимости»

1. Все считывания телеметрии (R1–R14) реализуются на Android 8–16; недоступное фиксируется статусом, а не падением (thermal на API < 29, Usage Access и геолокация без выдачи).
2. Агент автоматически возвращается в сеть после перезагрузки (L2: ≈ 1 с после `boot_completed` на API 26) и держит MQTT 5 через TLS с CA стенда; HiveMQ-клиент работает на Android 8.
3. Протокол выдерживает потерю связи: LWT за 23–43 с, буфер событий 500/500 без потерь и дублей, команды с Expiry и Correlation Data.
4. ACL Dynamic Security по `%u` изолирует устройства; `disableClient` разрывает сессию за 16 мс; создание 1 000 клиентов — 0,56 с.
5. Симулятор на JVM: 1 000 клиентов — heap ≈ 114 МБ, ≈ 33 сообщ/с, потерь нет; для 10 000 — экстраполяция в пределах цели (не измерено).
6. Device Owner на эмуляторе: тихая установка, киоск, reboot, самовыдача разрешений (кроме Usage Access).
7. Ограничения: ресурсы агента (RS1/RS2) вне целей на debug-сборке; API 37 и реальные устройства не проверены — MVP-B.
