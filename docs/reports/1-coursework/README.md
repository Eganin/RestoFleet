## Эксперимент «MQTT vs REST-polling» (серия 2, `docs/experiments/results.md`)

16 прогонов, окно 600 с, 9 600/9 600 команд доставлено, пропажа 160/160 обнаружена, обрывов 0. Трафик REST больше MQTT в 1,6–2,0 раза (опрос 30 с) … 4,2–5,7 раза (5 с); задержка команды MQTT p50 10,9–12,3 мс, p95 ≤ 16,3 мс, у REST ≈ ½ интервала опроса; CPU сервера у REST выше в 5–7 раз (N = 1 000) и 12–17 раз (N = 5 000) по среднему — его определяет повторная проверка bcrypt раз в TTL кэша Basic, по медиане (вклад опроса) — в 3,6–9,8 раза при N = 5 000; обнаружение пропажи MQTT 41–46 с, REST 2,4–2,9 интервала опроса. Оговорки — `results.md` и глава 4 записки (4.7).
