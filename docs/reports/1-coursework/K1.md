## 1.1 Аудит протокола: `shared:protocol` против ТЗ 7.1–7.4 (P1–P10) и FR-AG

Сверялись DTO (`shared/protocol/.../dto`), `Topics`, фикстуры `docs/protocol/fixtures` (на начало вехи — 17) с ТЗ v0.3 разд. 7.1–7.4, 8.2 и FR-AG-30…72.

| # | Где | Расхождение | Как закрыто |
|---|---|---|---|
| A1 | `events` | Нет события `threshold` (FR-AG-40, реш. 202) | `ThresholdEventDto` + `event-threshold-enter/exit.json` (1.2, реш. 218) |
| A2 | `events` | Нет `fg_changed` и `fg_absent` (FR-AG-41) | DTO + фикстуры (1.2, реш. 220) |
| A3 | `shadow/desired` | FR-AG-30 «ожидаемый статус» цели — поля нет | `ProbeTargetDto.expectedStatus: Int?` + `shadow-desired-expected-status.json` (реш. 219) |
| A4 | `cmd/req` | Параметры `run_probe`, `collect_diagnostics` в ТЗ не заданы; фикстур нет у `ping`, `collect_diagnostics`, `launch_app`, `run_probe`, `beep`, `reboot`, `lock_task` | `CommandTypes` + фикстура на каждый тип (1.3, реш. 221); тест `everyCommandTypeHasFixture` |
| A5 | `cmd/res` | Нет фикстур `succeeded` (с `result`) и `failed` | `cmd-res-succeeded`, `cmd-res-failed-expired`, `cmd-res-failed-invalid-params`; тест `everyCommandStatusHasFixture` |
| A6 | `cmd/res.result` | ТЗ: только строковые значения; DTO — любой `JsonObject` | DTO не сужен (реш. 221), тест `commandResultValuesAreStrings` проверяет фикстуры |

| A14 | `events` | Неизвестный `type` события не декодируется (`SerializationException`) | Оставлено: по плану 2.2 нечитаемое сообщение бэкенд подтверждает, считает и пишет в лог без payload. Для `PollTelemetryRequestDto` неизвестное событие ломает весь запрос — REST-клиент только симулятор той же версии |

Совпадает с ТЗ без правок: `status` (P3 `connId`, `bootId`, `device`, `role` опускается), `telemetry`, `probe` (классы ошибок FR-AG-32), `shadow/desired` и `reported` (P-структура, `appliedVersion`, `appliedAt`, `errors`), `cmd/req` (P2 `expiresAt`), `cmd/res` (P1 `received`). P4–P8 и P10 к DTO не относятся (брокер, бэкенд). Статусы `queued`/`delivered`/`expired` — серверные (REST API КМ2), в MQTT-DTO их нет намеренно.
