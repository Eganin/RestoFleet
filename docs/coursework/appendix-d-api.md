# Приложение Г — Эндпоинты REST API

Эндпоинты приведены по спецификации OpenAPI 3.0.3 серверной части (`docs/openapi.yaml`), которая отдаётся вместе со Swagger UI по пути `/swagger`; соответствие маршрутов Ktor спецификации проверяется тестом. Перечень приведён в таблице Г.1.

Таблица Г.1 — Эндпоинты REST API (префикс `/api/v1`)

| Запрос | Назначение | Аутентификация |
|---|---|---|
| `GET /health` (также без префикса) | Состояние серверной части: БД и брокер | Нет |
| `POST /auth/login` | Вход, выдача маркеров доступа и обновления | Нет, частота ограничена |
| `POST /auth/refresh` | Замена маркера обновления | Маркер обновления в теле |
| `GET, POST /restaurants` | Список ресторанов; создание ресторана | JWT |
| `GET, PATCH /restaurants/{id}` | Карточка ресторана; частичное изменение | JWT |
| `GET /devices` | Список устройств с фильтрами по ресторану, роли и статусу | JWT |
| `GET /devices/{id}` | Карточка устройства: реестр, последняя телеметрия и сессия | JWT |
| `DELETE /devices/{id}` | Вывод из эксплуатации | JWT |
| `GET /devices/{id}/telemetry`, `…/probes`, `…/events` | История телеметрии, проверок, событий | JWT |
| `GET, PUT /devices/{id}/shadow` | Тень с дельтой; изменение `desired` слиянием | JWT |
| `POST /devices/{id}/commands` | Команда устройству | JWT |
| `GET /commands/{cmdId}` | Команда и её статус | JWT |
| `POST /provisioning/tokens` | Одноразовый код регистрации | JWT |
| `POST /provisioning/tokens:batch` | Пакет из 1…1 000 кодов для симулятора | JWT |
| `POST /provision` | Обмен кода на учётные данные устройства | Нет, частота ограничена |
| `POST /poll/telemetry` | Телеметрия, результаты проверок и события одним запросом | HTTP Basic устройства |
| `GET /poll/commands` | Команды устройства в статусе `queued` | HTTP Basic устройства |
| `POST /poll/commands/result` | Итог команды | HTTP Basic устройства |
