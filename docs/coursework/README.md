## Соглашения

- **Заголовки** (ГОСТ 7.32): `# Введение`, `# 1 Теоретическая часть`, `## 1.1 …`, `### 1.2.1 …` — номер без точки в конце.
- **Таблицы**: строка-подпись перед таблицей `Таблица N.M — Название`, затем Markdown-таблица. Нумерация в пределах главы; в тексте ссылка «таблица 2.4» до самой таблицы.
- **Рисунки**: маркер отдельной строкой `[[FIG: id | Подпись | что нарисовать]]`. Номер рисунка = номер главы + порядковый номер маркера в главе; в тексте ссылка «рисунок 2.3» стоит до маркера. Генератор docx подставляет картинку `docs/coursework/img/<id>.png` (если её нет — рамку с описанием).
- **Источники**: `[n]`, несколько — `[2; 3]`. Номера присваиваются по порядку **первого упоминания** во всей записке (введение → главы → заключение); `99-sources.md` пронумерован так же. Электронный ресурс: `Название // Сайт. — URL: … (дата обращения: ДД.ММ.ГГГГ). — Текст : электронный.`
- **Листинги**: блоки ```` ```json ```` / ```` ```kotlin ```` — короткие (до ~10 строк), длинные фрагменты — в приложения.
- **Стиль**: научный, безличные конструкции, без маркетинга; не упоминать ИИ и инструменты генерации текста. Факты только из источников или из отчётов проекта (`docs/reports/…`, `docs/stages/0-mvp-feasibility.md`), цифры с оговорками сохранять как есть.
- **Объём** (страница ≈ 1800 знаков): введение ≈ 2–3 стр., главы ≈ 10–12 стр. каждая.
