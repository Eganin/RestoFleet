## Соглашения

- **Заголовки** (ГОСТ 7.32): `# Введение`, `# 1 Теоретическая часть`, `## 1.1 …`, `### 1.2.1 …` — номер без точки в конце. Приложение: `# Приложение А — Название`, подразделы `## А.1 …`.
- **Таблицы**: строка-подпись перед таблицей `Таблица N.M — Название`, затем Markdown-таблица. Нумерация в пределах главы (в приложении — `А.1`); в тексте ссылка «таблица 2.4» до самой таблицы.
- **Рисунки**: маркер отдельной строкой `[[FIG: id | Подпись | что нарисовать]]`. Номер = номер главы (буква приложения) + порядковый номер маркера; ссылка «рисунок 2.3» стоит до маркера. Картинка — `docs/coursework/img/<id>.png`, иначе `docs/experiments/img/<id>.png` (графики `analyze.py`, без копии), иначе рамка с описанием.
- **Источники**: `[n]`, несколько — `[2; 3]`. Номера — по порядку **первого упоминания** (введение → главы → заключение), `99-sources.md` пронумерован так же; в приложениях новых источников нет. Следующий новый источник — **55**.
- **Листинги**: в главах — до ~10 строк; фрагменты кода — в приложении Б, строки не длиннее 77 знаков, пропуски помечены `// …`.
- **Стиль**: научный, безличные конструкции; ИИ и инструменты генерации не упоминаются; номера решений журнала и находок ревью не цитируются (реш. 293). Факты — из источников, кода или отчётов проекта; цифры эксперимента — только серия 2 (`docs/experiments/results.md`, `data/*.csv`) с оговорками.
